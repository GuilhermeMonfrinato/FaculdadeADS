# Guia e Verificador de Cibersegurança Comunitária

Aplicação web pública e gratuita desenvolvida como parte das **Atividades Curriculares de Extensão Universitária**. O projeto visa promover o letramento digital e a segurança cibernética para cidadãos leigos, pequenos comerciantes e a comunidade em geral.

## 🎯 Objetivo da Ação
Democratizar o acesso a ferramentas práticas de segurança digital, auxiliando a comunidade na prevenção de golpes cibernéticos e no fortalecimento de credenciais de acesso no ambiente virtual.

## 🚀 Funcionalidades
- **Verificador Rápido de Senhas:** Avalia em tempo real a complexidade de senhas diretamente no navegador do usuário, garantindo total privacidade (sem envio de dados para servidores).
- **Cartilha de Prevenção a Golpes:** Orientações diretas sobre como se proteger do golpe do WhatsApp, ataques de phishing e fraudes via PIX.

## 💻 Tecnologias Utilizadas
- **HTML5:** Estruturação semântica da página.
- **Tailwind CSS:** Interface responsiva e acessível via CDN.
- **JavaScript (ES6):** Validação e interatividade em tempo real no lado do cliente (Client-side).

## 🌍 Como Acessar
O projeto pode ser executado diretamente em qualquer navegador atual sem a necessidade de instalação de dependências ou softwares externos.
